# FitBae

FitBae is a couple-first workout planner and session tracker. The runnable Vite application lives in [`FitBae/`](./FitBae).

```bash
cd FitBae
npm install
npm run dev
npm test
npm run build
```

After the app dependencies are installed, the root scripts also proxy to the application directory for development and CI.

See [`FitBae/README.md`](./FitBae/README.md) for environment and deployment setup.
